# 深度拆解协议（全文级逐图拆解）

> **定位**：`weekly-sop.md` ⑧-b「热点速览」的**下沉模块**。速览的「典型文献思路拆解」是**表格级**（摘要级信息可支撑）；本协议是**全文级**（须有 PMC 全文），粒度到每一张图的设计参数与论证作用。
> **由先生 2026-09-25 明确提出**：*"我要的是类似视频中这样比较细致的拆解"*。此处固化其格式与硬约束。

---

## 一、什么时候做

| 触发 | 说明 |
|---|---|
| 先生在热点速览中点名某篇 | 首选路径 |
| 某个热点与先生当前课题直接相关 | 与 `00_系统` 选题记录对表后决定 |
| 本期出现「结构可整体迁移」的范本 | 如中药/天然产物八步法这类骨架 |

**不做的情况**：单篇拆解成本约等于速览全篇。**每期建议 ≤2 篇**，否则挤占周课其余两件套。

```bash

python3 - <<'EOF'
import csv

for r in rows:
    if r['pmid'] in ('<PMID>',):
        print(r['pmid'], r['oa'], r['pmcid'], r['if_latest'])
EOF
# 2) 抓全文并结构化导出
python3 <skill>/scripts/fetch_pmc_fulltext.py --id <PMID> \
  --out-dir 04_IMRAD架构库/_pmc_cache --dump-md 07_深度拆解/_fulltext/<PMID>.md
```

- **非 OA / 无 PMCID → 只能做摘要级拆解**，头部标 `depth: abstract-only`，**禁止**写方法学细节与图注级判断。
- W39 实测可全文率：全池 **273/520（52.5%）**；但 `>10` 区间仅 **14/53（26%）**。
  → **高 IF 文献多数做不了全文级深拆**，这是选篇的硬约束，须在交付时如实说明。

## 四、五段结构（缺段即不合格）

### 0. 三十秒版
一句话讲清「它做对了什么」，并列出 2–3 个骨架动作。**给不读长文的人看。**

### 1. 全局骨架表
| 步 | 图 | 这一步做什么 | 在论证链中的作用 | **抽掉这一步会怎样** |

最后一列是本协议的核心——**它强制回答「每一步的必要性」**，而不是罗列步骤。

### 2. 逐图拆解（主体，占比 ≥ 60%）
每张图一节，固定回答四问：

1. **这一步要解决什么**（该步的研究任务）
2. **怎么做的**（**真实参数**：动物/细胞、分组、剂量、时间点、仪器、阈值、统计方法）
3. **得到了什么**（原值，含关键百分比与 p 值）
4. **在链条中的位置 + 设计上的讲究**（可偷的部分）

**必须写「设计上的讲究」**：指出该图里哪个取舍是刻意的、为什么这么取舍。这是与普通总结的分水岭。

### 3. 三个关键设计决策
从全篇提炼 2–4 个**可迁移到先生课题**的决策，每个写「为什么对」+「代价是什么」。

### 4. 可迁移模板
把骨架抽象成 N 步流程表，每步给「动作 / 产出 / 成本量级」。若先生走纯生信路线，**须明确标出哪几步无法用公共数据替代**，并给出折中方案。

### 5. 弱点清单（**两段式，不得合并**）
- **作者自陈**：逐条摘 Discussion 的 limitations 原意
- **本拆解分析补充**：核读后发现的、**原文未述**的问题

## 五、硬约束（红线）

1. **区分「原文所载」与「本拆解分析」。** 所有分析性判断必须显式标注，不得与原文事实混排。
2. **图注与正文必须交叉核对。** 这是本协议**唯一能稳定产出增量价值**的环节。已验证的核对点：
   - 取材部位是否一致（实例：正文/Methods 写回肠 *ileum*，图注写结肠 *colonic*）
   - 补充图中出现的实体是否在正文出现（实例：图8 提 *Blautia* 与 Bacillota 增加，正文属水平未提）
   - 细胞类型归属是否有对应实验（实例：图8 写 "macrophage-mediated NF-κB"，但 WB 用肝组织整体裂解，无细胞类型证据）
3. **识别「替代标志声称高阶机制」。** 高危句式：
   - 用 Ly6G/MPO 共定位声称 **NET 形成**（正确标志应为 citH3 或 MPO-DNA 复合物）
   - 用 bulk 裂解声称**特定细胞类型**的信号
   - 用相关声称**因果**（须显式写「相关 ≠ 因果」）
   → 这类越界是审稿人高频狙击点，**必须在弱点清单中点名**。
4. **剂量换算逻辑必查。** 若文中成分剂量非按占比换算（本文实例：CWP 50/100 mg/kg 未按其在粗提物中 9.45% 的占比折算），则「该成分是主要活性成分」这一结论**强度不足**，须指出。
5. **数值一律可核验。** 所有引用的百分比、p 值、仪器参数须能在全文 XML 中检索到。
   ⚠️ **注意 U+00A0（`\xa0`）**：Europe PMC 返回文本含不间断空格，用普通空格做匹配会**失配**。用 `fetch_pmc_fulltext.py`（已内置规范化）或先替换再检索。
6. **不编造**：作者未做的实验不得写成"未充分验证"以外的话；未报的数值标「原文未报」，不估算。
