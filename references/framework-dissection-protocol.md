# 论文框架拆解协议（日课 ①-b，逐篇）

> 目标：把“读到了什么结论”升级为“**作者怎么想出来的、怎么让逻辑自洽、用什么方法把哪个问题讲清了**”。
> 与另两份协议的分工必须先看清，否则会重复劳动或降级成摘要复述。

## 一、三层拆解的分工（不可混用）

| 协议 | 节奏 | 深度 | 回答的问题 | 产出 |
|---|---|---|---|---|
| **本协议**（框架拆解） | **日课，逐篇** | 摘要级→图注级（少数全文） | 这篇的**论证骨架**长什么样、承重点在哪 | `框架拆解_<周次>_D0n.md` + 累积库 |
| `imrad-anatomy-protocol.md` | 周课 ⑨ | 50 篇统计 | 一批论文的**结构分布**（段数/句长/子标题/局限形态） | `04_IMRAD架构库/<周次>_IMRAD拆解.md` |
| `deep-dissection-protocol.md` | 按需 | 全文逐图 | 一篇的**证据链**如何逐图搭起来 | `07_深度拆解/<篇名>.md` |

**一句话区分**：本协议看**骨架与承重点**；IMRAD 扫面看**统计分布**；深拆看**证据颗粒**。

---

## 二、每篇必答的三问（先生 2026-10-18 指定）

| # | 问题 | 不合格的回答 | 合格回答的形态 |
|---|---|---|---|
| Q1 | **作者如何构思** | “作者研究了 X 对 Y 的影响” | 作者从哪个**已知矛盾/异常**切入，为什么选这个对象与这个模型，先证什么后证什么（顺序即构思） |
| Q2 | **如何让逻辑自洽** | “结果支持结论” | 点明**自洽装置**：对照设置、剂量/时间梯度、正交方法、排除替代解释、边界声明——哪一件在堵哪个洞 |
| Q3 | **用什么方法讲清了什么问题** | “用了 RNA-seq 和 qPCR” | 方法 ↔ 问题的一对一映射：哪个方法解决**因果**、哪个只解决**相关**、哪个负责**外推**；方法有没有超配或欠配 |

三问各须给**证据位置**：摘要原句、图号、或 Methods 小节名。**给不出位置 = 没读到，按未完成计。**

## 三、快速卡（7 字段，全部 74 篇都填）

> 摘要级也能填 5 个字段（标 `depth: abstract`）。**禁止因为拿不到全文就跳过整篇。**

| 字段 | 写法 | 判据 |
|---|---|---|
| F1 问题类型 | `描述 / 机制 / 预测 / 干预 / 方法学 / 资源建库`（可多选，首位为主） | 与摘要末句的动词一致 |
| F2 论证主轴 | 一句话：`因为 X，所以 Y，证据是 Z` | ≤25 字，须含因果连接词 |
| F3 三段骨架 | `起点（已知）→ 转折（缺口）→ 落点（新增知识单元）` | 转折句必抄原文 |
| F4 自洽装置 | 从下表勾选，写“装置→堵的洞” | ≥2 项，且至少 1 项是**排除替代解释**类 |
| F5 承重点 | 全文 1–2 个 load-bearing claim；其余都是支撑 | 删掉它结论就塌的那句 |
| F6 方法-问题匹配 | `充分 / 超配 / 欠配`，欠配须写缺什么 | 因果结论用相关设计 = 欠配 |
| F7 最小充分论证集 | 若只保留 3 个结果，留哪 3 个；删掉哪个会塌 | 与 F5 呼应 |

### F4 自洽装置清单（勾选式）

| 类别 | 装置 | 堵的洞 |
|---|---|---|
| 对照类 | 阴性对照 / 溶剂对照 / 敲低-回补（rescue） / 同型对照 | “是不是非特异效应” |
| 梯度类 | 剂量梯度 / 时间序列 / 浓度-反应 | “是不是阈值现象、能否排除偶然” |
| 正交类 | 第二种方法复现同一结论 / 独立队列 / 体内外互证 | “是不是单一方法的假象” |
| 排除类 | 排除替代通路 / 竞争性实验 / 混杂校正 | “有没有别的解释” |
| 边界类 | 限定人群/模型/剂量/时间窗 | “结论能推到多远” |
| 逻辑类 | 必要条件与充分条件分开证 / 上下游顺序实验 | “因果方向” |

**没有排除类装置的机制论文，承重点按“相关”计，不得当因果读。**

## 四、展开卡（每日 ≥3 篇，深一层）

在快速卡基础上加四段，每段 60–120 字：

1. **构思还原**：如果我是作者，在第 1 张图之前我会先想清哪三件事？作者显然想清了哪件、漏了哪件。
2. **自洽缺口**：这套装置链最薄的一环在哪（通常是 F6 的欠配处或 F4 缺排除类）。
3. **可迁移的论证动作**：抽象成不带领域词的骨架，例如
   `先在体外建立剂量依赖 → 再用遗传学手段切断通路 → 最后用回补恢复表型，形成三段闭合`。
4. **若我来写，最可能写坏的地方**（承接 `writing-craft-taxonomy.md` 第二问第 6 条）。

## 五、累积库：论证原型的归类（每周结算）

> 位置 `04_IMRAD架构库/A_框架拆解累积.md`，**只增不减**。归类不是贴标签，是为了让先生下次选题时能“按原型选模板”。

| 原型 | 判别特征 | 典型论证链 |
|---|---|---|
| P1 填补空白型 | 缺口明确、结论是“首次在 X 中证明 Y” | 缺口 → 单点验证 → 边界 |
| P2 推翻旧说型 | 与既有结论冲突，须先复现再反驳 | 复现旧结果 → 找差异变量 → 证明旧结论的适用条件 |
| P3 机制串联型 | 上下游分子链 | A→B→C，逐段切断与回补 |
| P4 尺度跨越型 | 体外→体内→人群 | 每跨一层补一次验证 |
| P5 方法替代型 | 新方法 vs 金标准 | 一致性 + 优势场景 + 失效边界 |
| P6 人群外推型 | 结论从 A 人群推到 B 人群 | 分层 + 交互检验 + 校准 |
| P7 负结果澄清型 | 否认既有关联 | 功效计算 + 混杂控制 + 等价性检验 |
| P8 资源建库型 | 数据集/图谱 | 规模 + 质量门槛 + 可用性示例 |

每周统计：本周 74×7 篇中 P1–P8 分布、以及**先生所在方向最常用但最薄弱**的原型（通常是 P2、P7——最难写）。

## 六、硬约束

1. **禁止流水账**：“作者先做了 A，然后做了 B”不是框架拆解，是实验记录转述。
2. **禁止无位置断言**：任何“作者意在……”必须附摘要原句或图号；否则写 `[推断，未核]`。
3. **深度决定强度**（R4）：`depth: abstract` 的卡片不得评价方法学细节与统计。
4. **不得只写优点**：每篇至少 1 条“这套骨架的薄处”，否则视为未拆。
5. **每日产出计数**：快速卡 ≥74 张、展开卡 ≥3 张；不足即当日未完成（L3）。
