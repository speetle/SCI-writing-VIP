# 顶刊级叙事与论证标准

> 用途：① 判定一个研究故事是否“值得解决、讲得透、立得住”；② 用多篇对比扫描定位缺口；③ 用图表论证链检验每张图的存在理由。
> 适用场景：选题评估、大纲设计、Discussion 重写、投稿前自审。

---

## 一、三把尺子（先生 2026-10-18 指定）

每个维度按 **0 / 1 / 2** 打分，满分 6。

| 维度 | 0 分 | 1 分 | 2 分 | 判据问句（必须能给出证据） |
|---|---|---|---|---|
| **现实痛点** | 只有“学术上没人做过” | 有临床/产业关联但未量化 | 有可量化负担或可避免损失（发病率、死亡、成本、失败率、误判率） | 不解决它，谁会付出什么代价？代价有多大？有无文献数字 |
| **理论进展** | 只是重复验证 | 补充一个变量或一个场景 | 改变领域对某机制的判断（建立/推翻/限定条件） | 本文结论若成立，哪些既有表述必须改写？写出被改写的那句 |
| **关键机制** | 停在相关 | 找到一个中介但未证因果 | 给出必要且充分性证据（切断+回补/上下游顺序/正交验证） | 哪一步实验排除了“只是伴随现象”？ |

### 判定门槛

| 总分 | 判定 | 动作 |
|---|---|---|
| 6 | 顶刊级故事 | 按顶刊标准写（图表链须闭合） |
| 4–5 | 可投高分刊 | 补齐低分维度的证据，或把低分维度从卖点中删掉 |
| 2–3 | 需重构 | 换角度（通常是换 gap 或换对象），不要靠润色补救 |
| 0–1 | 不建议投 | 重做选题 |

**常见误判**：把“首次”当理论进展。首次只在**别人做不到**（受技术/样本限制）时才值 2 分；否则只是 1 分。

## 一-bis 故事质量四问（先生 2026-10-18 原话的四项要求）

> 三把尺子判“值不值得做”，四问判“讲没讲成”。**四问全过才算顶刊级故事**；任一不过，先改结构，不许靠润色补救。

| # | 质量 | 一句话定义 | 不合格表现 | 检验动作（当场可做） |
|---|---|---|---|---|
| Q1 | **透彻** | 读者能复述“问题—做法—发现—改变”，且明白每一步为什么必要 | 只报结论不讲推理；段落可任意调序 | 60 秒口述 + 把图序倒读：倒读仍通 = 没有推理链 |
| Q2 | **可信** | 每个承重结论都有可定位证据，且主要替代解释已被排除 | 相关写因果；单模型写普适；用“显著”代替效应量 | 对每个承重点问两句：哪张图？排除了哪种别的解释？ |
| Q3 | **有启发性** | 结论能抽象成别人可接着用的命题或方法，不止于“本对象上成立” | 结论止于“A 影响 B”；启示写成“有助理解” | 写出**一句可迁移命题** + 一个别人能接着做的实验 |
| Q4 | **为什么值得解决** | 不解决它会付出什么代价，代价可量化 | 只说“首次”“尚无人研究”；代价无数字 | 三连 so-what，第三次仍须落在领域级答案 |

**Q3 的可迁移命题格式**（写完才算过）：

```
在 <条件集合> 下，<对象> 的 <行为> 由 <机制> 决定；因此 <干预/测量> 可用于 <判断或分型>。
```

**四问与三把尺子的关系**：Q4 ≈ 现实痛点，Q2 ≈ 关键机制 + 证据链，Q1 ≈ 叙事闭环，Q3 是把理论进展翻译给别人用。**三把尺子给分，四问给判决**。

## 二、多篇对比扫描（选题与讨论的共用工具）

### 步骤

1. **定域**：用同一核心对象/同一疾病/同一通路圈定 **8–15 篇**（近 5 年为主，含 1–2 篇奠基性旧文）。
2. **建矩阵**（每篇一行）：

| 列 | 填什么 |
|---|---|
| 研究问题 | 一句话，写成疑问句 |
| 对象/模型 | 物种、细胞系、人群、剂量、时间窗 |
| 方法 | 只填决定证据等级的那 1–2 个 |
| 核心结论 | 一句话，含方向 |
| 证据等级 | 相关 / 因果 / 干预 / 人群 |
| 未解决 | 作者自己承认的 + 你读出来的 |
| 与本文关系 | 支持 / 冲突 / 正交 / 前置 |

3. **三类判定**（这是扫描的唯一目的）：

| 判定 | 操作定义 | 用途 |
|---|---|---|
| **已解决透彻** | ≥3 篇独立研究、不同模型、结论一致 | 不要再做；写进 Intro 的①或②，1 句带过 |
| **仍存空白** | 无人做 / 只有单一模型 / 只有相关证据 | 候选 gap，须再问“为什么此前做不到” |
| **结论矛盾** | 两篇以上结论方向相反 | 最高价值缺口，见下 |

### 矛盾处的处理规则（硬约束）

不得只写 `results have been conflicting`。必须完成三步：

1. **定位差异变量**：人群、模型、剂量、时间窗、终点定义、统计口径、随访长度——逐项比对。
2. **提出可检验假设**：`若差异源于剂量，则 <低剂量组> 应复现 A 的结论`。
3. **用本文数据或文献二次分析检验该假设**；检验不了就标注 `未能区分，待专门设计`。

**做不到第 2 步的矛盾，只能写进局限，不能当卖点。**

## 三、叙事闭环：Gap Ledger（缺口-证据对齐表）

> 这是“故事讲得透”的可验证形式。任何一行空着，闭环就不成立。

| # | Intro 的 gap 子句 | 服务它的设计（Methods） | 回答它的结果（图/段） | Discussion 回指句 | 状态 |
|---|---|---|---|---|---|
| 1 | 原句抄录 | 具体设计名 | 图 2C / R 第 2 段 | 首段第 2 句 | ✅ / ⬜ |
| 2 | | | | | |

### 三类典型断链

| 断链 | 表现 | 修法 |
|---|---|---|
| 有缺口无设计 | Intro 提了机制缺口，Methods 只有相关性分析 | 删缺口，或补实验 |
| 有设计无回答 | 做了实验，Results 没把它写成对缺口的一次回应 | 改 Results 主题句，让其显式回指 |
| 有回答无回收 | Discussion 首段没回指 gap，直接讲意义 | 加回指句，并把贡献限定在该 gap 内 |

### 讨论的“回到缺口”三句（结构固定）

1. `We tested whether <gap 句> and found <方向>.`（回收）
2. `This <confirms / refines / overturns> the view that <被改写的那句>.`（贡献）
3. `It does not address <未覆盖的边界>.`（边界，紧接局限段）

## 四、图表论证链（Figure Ledger）

### 每张图必答六问

| # | 问题 | 不合格表现 |
|---|---|---|
| 1 | 它支撑哪个 claim？ | 答不出具体句子，或对应“多个结论” |
| 2 | 为什么用**这个图型**？换别的会丢什么？ | “一直都用柱状图” |
| 3 | 为什么放在**这个位置**？前置依赖是什么？ | 位置可按任意顺序调换 |
| 4 | 它**证明了什么**（一句话，含方向）？ | 只能描述“展示了 X 的变化” |
| 5 | 它**不能证明什么**（边界）？ | 答不出 → 通常意味着正文过度解释 |
| 6 | 与前后图是什么关系（递进/并列/正交/收敛）？ | 关系为“并列但结论相同”→ 可合并 |

### 图型 ↔ 论证任务对照

| 论证任务 | 首选图型 | 常见错误 |
|---|---|---|
| 组间差异（连续变量） | 散点/点图 + 中位数（n 小必用） | 柱状图+误差棒遮住分布 |
| 时间过程 | 折线（含个体轨迹） | 只画终点柱状图 |
| 生存/结局 | Kaplan–Meier + 风险人数表；多因素用森林图 | KM 不给 log-rank 与 HR |
| 剂量-反应 | 拟合曲线 + 实测点 | 只给两个剂量做柱状对比 |
| 多指标多维 | 热图（须给标准化方式与聚类参数） | 未标 z-score 方向 |
| 诊断性能 | ROC + AUC（含 95% CI）+ 校准曲线 | 只给 AUC 不给阈值与校准 |
| 空间/定位 | 代表图 + 定量（不得只给图） | 只给“漂亮的”代表图 |
| 因果链（通路顺序） | 遗传学/药理学切断 + 回补，组合图 | 只给相关性的共变曲线 |
| 结构/结合 | 结构图 + 生化验证正交 | 只给预测结构 |

### 主图 vs 补充图的分工判据

| 进主图 | 进补充图 |
|---|---|
| 缺口的直接回答 | 方法验证、抗体特异性、批次一致性 |
| 承重点（F5）所需的必要证据 | 重复实验的额外验证 |
| 改变读者判断的那一张 | 只增加信心、不改变结论的 |

判据一句话：**删掉它，主结论是否失去支撑？** 是→主图；否→补充。

### 序列范式（四选一，全篇统一）

| 范式 | 结构 | 适用 |
|---|---|---|
| 递进链 | 图1现象→图2机制→图3因果→图4外推 | 机制类标准 |
| 分叉验证 | 主图1后，图2/3 分别独立验证同一结论 | 争议大的结论 |
| 正交三角 | 三种不同方法指向同一结论 | 方法学/结构 |
| 漏斗收敛 | 全景筛选→逐步收窄→单点确证 | 组学/生信 |

**混用两种范式**是高分稿被拒的常见结构问题：读者会在第 3 张图失去预期。

## 五、故事可讲性测试（写前先过，写后复测）

| 测试 | 做法 | 通过标准 |
|---|---|---|
| 60 秒口述 | 不看稿，讲给同行听 | 对方能复述“问题-做法-发现-改变”四件事 |
| 三连 so-what | 连续问三次“所以呢” | 第三次仍能给出领域级答案，不落到“有助理解” |
| 反向测试 | 把结论反过来写 | 若反结论也“说得通”，说明证据不足以区分 |
| 删除测试 | 删掉任意一张图 | 若故事仍完整，该图应移入补充 |

## 七、硬约束

1. 图表结论必须来自**本人读过的图注与正文**；未读全文不得评价图型是否恰当（R4）。
2. 矛盾处不得用“存在争议”搪塞（见 §二）。
3. 贡献句（C 句）不得超出承重点证据边界；边界外内容只能写入展望。
4. 任何“顶刊都这样做”的表述必须附**具体篇数与刊名**，否则不写。
