# 语言范式提取口径（阶段 ②）

> 目的：拆解**真人如何表达**——用什么句式、句子多长、连接词怎么用、语气多强、思虑多周到。
> 核心方法：**样本 A（PubMed 真人原文） vs 样本 B（我产出的文本）显式对照**，不套用通用 SCI 模板。

---

## 一、四类清单（对应四个累积文件）

### ① 地道高频学术句式清单 → `A_地道句式清单.md`

按**使用位置**分类，不按语法分类：

| 分区 | 采集对象 |
|---|---|
| 引言·背景铺陈 | 疾病定性、流行病学陈述、"已知机制"句式 |
| 引言·缺口指出 | `remains unclear` / `has not been elucidated` / `with incompletely understood ...` 及其**后果绑定** |
| 引言·目的陈述 | `We aimed to` / `Here, we present` / `To address these limitations` |
| 方法描述 | 数据源、筛选-验证骨架、工具清单长句、统计报告 |
| 结果陈述 | 剂量-反应、并列压缩、阴性结果、校正后数值 |
| 讨论·解读 | 降级动词 + 限定名词组合；因果未证时的语法选择 |
| 讨论·对比与局限 | `whereas` 并列矛盾；领域级方法学局限 |
| 讨论·展望 | 具体待办清单 + 准入门槛 |

**条目强制格式**：
```
**编号｜一句话命名**
- 原文：*"..."*　`PMID xxxxxxxx`｜期刊｜IF 区间｜模式
- 机制：<为什么这样写有效>
- 迁移模板：`<可复用骨架>`
- 适用：<论文哪一部分>
- ⚠️ 反面：<AI 常见写法>（若有）
```

### ② 逻辑衔接范式 → `B_逻辑衔接范式.md`

按**衔接场景**采集，每个场景给出真人做法 + AI 做法对照：

1. 转折：段首 `However,` 的**使用配额**（每段 ≤1 次）+ 句内 `but`/`whereas` 的下沉用法
2. 缺口 → 本研究：介词/分词短语过渡（`To address these limitations,` / `Leveraging X,`）——**零连接词过渡**
3. 结果链条推进：句中副词（`further` / `also` / `Subsequently,`）
4. 文献对比：一句内 `whereas` 并列两个结论
5. 收束与展望：标记词全篇 ≤1 次 + 必须带具体内容

**必须给出密度基线**（实测，每百句）：见 `C_真人写作习惯.md` 基线表。

### ③ 真人写作习惯特征 → `C_真人写作习惯.md`

两类内容：
- **量化基线**（每周更新）：平均句长、句长 SD、短句/长句占比、连接词密度与种类数、hedge 密度、booster 密度、hedge/booster 比、TTR。
- **习惯条目**：每条须"可操作"——能转成写作时的动作或红线。示例：负面结果 ≤25 词且带数值；结论句至少 1 个降级动词 + 1 个限定名词。

### ④ AI 腔对照黑名单 → `D_AI腔黑名单.md`

分四组：模板短语 / 语气类 / 句法类 / 中译英直译。每条含：触发条件、判为 AI 腔的依据（**尽量用实测频次**，如"本语料 864 句中 0 次"）、真人替代（引句 + PMID）、检测方式。

## 二、样本 A / 样本 B 对照方法

| 步骤 | 做法 |
|---|---|
| 1 | 用 `extract_language.py --dump-abstracts` 生成**样本 A 语料**（当日真人摘要） |
| 2 | 用 `style_compare.py --human <A> --mine <B>` 得到逐项差值与判定 |
| 3 | 对每个 ⚠️ 项，**回到样本 A 找出替代写法**，写成"原句 → 修正句 → 依据（PMID）" |
| 4 | 机检无法覆盖的项（语气、思辨度、逻辑跳跃）→ 人工逐段通读，用"可证伪性三问"：

> 1. 这句话删掉后，读者会损失什么信息？答不出 → 套话。
> 2. 这句话能不能原封不动搬到另一篇论文？能 → 无特异性。
> 3. 这句话的结论强度，有没有被数据/实验设计支持？没有 → 过度推断。

## 三、证据边界（写文件时必须标注）

- 引句来自**摘要** → 标 `[摘要级]`；只有读过全文的句式才可标 `[全文级]`。
- 关键词规则抽取存在**假阳性**（如含 `potentially` 的句子可能被归入 interpretation 而实际是背景句）。写入 A~D 前须**人工确认句子功能**。
- 单周统计**不能称"趋势"**；只有累积 ≥4 周且方向一致，才可写"趋势"。
- 代理指标（OpenAlex 2yrMCC）与官方 JIF **严禁混称**。

## 四、常用机检命令

```bash
# 语言原料（含文体指标）
python3 <skill>/scripts/extract_language.py --csv <当日 papers.csv> --out <原料.md> \
    --dump-abstracts <_human_corpus.txt> --dump-json <_lang_stats.json>
# 双样本对照
python3 <skill>/scripts/style_compare.py --human <_human_corpus.txt> --mine <我的稿.md> --out <_style_compare.md>
# AI 味机检
python3 <skill>/scripts/anti_ai_check.py --file <我的稿.md>
```
