# IMRAD 架构拆解口径（周课 ⑨⑩）

> 目标：不概括摘要，而是**拆开整篇文章的写作组织逻辑**，最终沉淀成可直接用于先生论文大纲设计与结构修改的《通用写作框架模板》。

## 一、样本选取（两步）

**第一步：50 篇结构扫面**
- 从本周池中按 IF 区间配额抽取：`>10` 15 篇、`5-10` 20 篇、`3-5` 10 篇、`1-3` 5 篇（可按本周实际分布微调）。
- 模式覆盖要求：**纯生信 ≥10 篇**，干湿结合 ≥10 篇，其余为实验为主。
- 采集项（可有全文用全文，无全文用摘要 + 公开元数据，并标注深度）：
  1. 章节顺序与章节标题写法
  2. Introduction 段落数与各段功能标签
  3. Methods 子标题体系（生信论文常见：Data acquisition / Processing / Model construction / Validation / Statistics）
  4. Results 子标题与图序的对应关系；图注首句句式
  5. Discussion 段落数与功能序列
  6. 是否有 Limitations 独立小节；写在 Discussion 内还是独立
  7. 段落平均句数、句长分布的**章内差异**（如 Methods 句长 vs Discussion 句长）

**第二步：2 篇深度拆解**
- 选取标准：① 深度可及（OA 且有全文）② 与本周热点契合 ③ 一篇高分区（`>10`）、一篇中等分区，以便对比。
- 全文获取顺序：PubMed Central OA 全文（`efetch db=pmc`）→ 出版社 OA 页面 → 若均不可及，降级为**摘要级 + 图注级**并**明确标注降级**（R4）。

## 二、逐段拆解要求

### 3-1 I（Introduction）
- 逐段列出功能：`背景 → 现有进展 → 矛盾/空白 → 科学问题 → 研究目的`
- 记录**段落数量**与**每段句数**；标出递进关系（哪一句在为下一个转折埋伏笔）
- 输出：本类论文引言段落数分布（如 3 段 24% / 4 段 52% …）与各段句数中位数
- 检查点：缺口句是否回答"不知道会损失什么"？

### 3-2 M（Methods）
- 解析章节组织顺序与子标题层级
- 生信部分的描述逻辑：数据来源 → 预处理 → 算法/参数 → 阈值 → 软件版本 → 统计方法
- **必写细节**：accession、样本量、版本号、阈值、多重检验校正、随机种子（若有）
- **可简写**：通用软件的标准流程、与本文结论无关的中间步骤
- 避坑点清单：何时用被动（主语为数据/基因）、何时用主动（主语为作者的研究决策）

### 3-3 R（Results）
- 判定叙事顺序：**按实验/论证逻辑** 还是 **按图表顺序**；统计两者比例
- 阳性结果陈述范式；**阴性结果**陈述范式（长度、是否辩解）
- 图表与正文分工：正文是否只写结论性数值
- **真人不会做的事**：不复述图表全部数字；不在结果段做机理解释（留给 Discussion）

### 3-4 D（Discussion）
- 标准链：`主要发现 → 与文献横向对比（一致/不一致如何解释）→ 机制解释 → 优势 → 局限 → 展望`
- **重点拆解 limitation 写法**：
  - 是自贬式（`Our study has several limitations`）还是领域级方法学批评？
  - 一条局限平均多少词？是否给出缓解措施？
  - 局限放在 Discussion 末段 vs 独立小节的比例
- 展望写法：是否含具体待办清单 / 准入门槛

### 3-5 综合输出
更新 `04_IMRAD架构库/通用写作框架模板.md`（**升版 + 更新日志**），并核对是否推翻了上一版的 `[待校验]` 条目。

## 四、硬约束

- 所有结构结论必须来自**实际统计的样本**，报告样本量与分布，禁止"一般来说""通常"这类无据表述。
- 未能获取全文的篇目，其结论标记为 `[摘要级]`，**不得**用于方法学细节判断。
- 发现与上周结论冲突时，**不得静默覆盖**：写明冲突与可能的解释，再决定是否修订框架。

## 五、执行方式（可复制）

```bash
# 1) 结构扫面：按 IF 配额抽 50 篇，抓 PMC OA 全文并统计
python3 <skill>/scripts/imrad_scan.py \
  --pool <周次>/papers_master.csv \
  --out 04_IMRAD架构库/<周次>_scan.json \
  --n 50 --cache-dir 04_IMRAD架构库/_pmc_cache
# 2) 从缓存导出候选深拆对象（选 1 高分区 + 1 中分区，均须 depth=full）
#    全文已缓存，二次解析不再联网
```

**扫面产出字段**（每篇）：`depth`(full/abstract)、`section_order`、`section_roles`、
各章 `n_para`/`n_sent`/`paragraph_sent_median`/`sent_words_mean`/`sent_words_sd`/
`short_pct`/`long_pct`、`subsections`、`fig_captions`、`fig_first_sent`、
`limitation_in_discussion`、`has_backmatter_limitations`、`abstract_labels`。

### 已验证的解析陷阱（务必保留）

| 陷阱 | 后果 | 处置 |
|---|---|---|
| 段落只取 `sec.findall("./p")` | 多数期刊把 `<p>` 放在**子章节**内，导致 M/R 章统计样本坍塌为 0（实测 28 → 2） | 改递归：`sec.findall(".//p")`，并 `if p.findall(".//p"): continue` 跳过容器节点 |
| PMC 把**图注**放在 `<body>` 的 `<p>` 里 | 抬高「段长」与「1 句长段」计数 | 深拆落盘后人工识别剔除（实测 high-IF 篇 36 段中 4 段为图注） |
| PMC ID 取自文献池 `pmcid` 列 | 该列可能被 `ArticleIdList` 陷阱污染（见 SKILL.md §7） | 建池后必跑 `repair_ids.py`，再据修复后的 `pmcid` 取全文 |

## 六、2026-W39 已确立的统计基线（后续周课须复算并对比）

**样本**：50 篇抽样（`>10` 15 / `5-10` 20 / `3-5` 10 / `1-3` 5；纯生信 ≥10、干湿结合 ≥10），**32 篇取得全文（64.0%）**

### 6.1 章内句长基线（**取代v0.1的摘要基线**）

| 章节 | 章节数 | 句长均值 | 句长 SD | ≤15 词短句 | ≥35 词长句 | 每段句数中位 |
|---|---|---|---|---|---|---|
| I | 31 | 24.2 | 8.9 | 16.7% | 12.2% | 5 |
| M | 28 | 21.1 | 10.2 | 33.0% | 8.3% | 4.8 |
| R | 28 | 21.0 | 9.9 | 33.7% | 8.9% | 5.5 |
| D | 53 | 23.9 | 7.9 | 16.5% | 10.6% | 5 |

**I+D = 24.0 词 / 短句 16.6%（n=84）｜M+R = 21.0 词 / 短句 33.4%（n=56）**
→ **事实章要短句，论证章要长句。**

### 6.2 章节顺序与分区

| IF 区间 | Methods 在 D 之前 | Methods 在 D 之后 |
|---|---|---|
| `>10` | 2 | **3** |
| `5-10` | 6 | 7 |
| `3-5` | **8** | 0 |
| `1-3` | 2 | 0 |

正文章节数中位 5；主流序列 `I M R D D`(6) 与 `I R D M D`(5)。

### 6.3 子标题句法

- **Methods 子标题：1% 为论断句**（319 个中 4 个）→ 一律名词短语。
- **Results 子标题：17% 为论断句**（204 个中 35 个），且有 IF 梯度：
  `>10` 53% ｜ `5-10` 45% ｜ `3-5` 59% ｜ `1-3` **0%**。
- **Discussion 不设子标题**（10 个 / 32 篇）。

### 6.4 Limitation 形态

| 形态 | 篇数 | 占比 |
|---|---|---|
| Discussion/Conclusion **正文段落**含局限表述 | **29/32** | **91%** |
| 设独立 `Limitations` 小标题 | **1/32** | **3%**（且系期刊模板） |
| `back` 区独立 Limitations 节 | 0/32 | 0% |

承载局限的段落**平均 9.7 句**（I/D 每段中位仅 5）。**局限是一整段，不是一句免责声明。**
