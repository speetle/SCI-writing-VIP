## ④ 阶段4｜AI 训练写作初稿（350–500 英文词）

产出：`05_仿写训练/<周次>/D0n/01_AI训练写作初稿.md`

**素材来源**：**③-bis 选定**的顶刊池 / 当日文献的真实科学内容。**禁止脱离原文凭空造科学内容。**

**流程**：
1. 选定题材：**优先取顶刊 reserve 池的近两年三大顶刊原文**；记录素材 PMID 与取材层（见 ③-bis）。
2. 选择段落类型：**Introduction 段** 或 **Discussion 段**（交替练习）。
3. 篇幅：**350–500 词**（硬性；超出或不足必须重写）。
4. **★ 起草时先做「问题表述」取向设定（L7，先生 2026-10-01 强化）**：
   在稿首声明块里明确写一句：**本次仿写要练的是「人类如何表述问题」的哪一个切面**，例如：
   - `本次练习：把「<具名现象>」写成**待决问题**，而不是「研究背景」`
   - `本次练习：用**强因果动词**（drives / shapes / determines）承载已证机制，不再用 may / could 兜底`
   - `本次练习：结论段**只留一句**肯定判断 + 一句具名局限，不写三层免责`
   ⚠️ **反面（AI 通病，先生明确点名）**：AI 写作「**太过保守，而人类不会**」。
   具体表现为把 `X drives Y` 写成 `X may contribute to Y`、把已证关联写成 `could be associated with`、
   在结论里连写「不构成／不等于／这并不代表…」连环免责。
   **数据支持时必须直接用 `confirms` / `drives` / `decreased` / `improved` 级动词**——
   这是**先生 2026-09-28 已定的结论措辞偏好**，与「阴性照实写、数值不预编」并列，**不是二选一**。
4. 稿首必须带：

```markdown
> ⚠️ 写作训练稿（Training Draft）— 用于写作技法练习，**不得投稿**。
> 素材来源：PMID <...>（<期刊>，IF 区间 <...>）｜未实测数值标 [TO BE MEASURED]
```

5. **允许保留现有 AI 写作习惯**——不刻意伪装完美，保持"可诊断"状态（这是阶段 ⑤ 的输入质量前提）。
6. **不得**为了好看而预先查黑名单改写；黑名单在阶段 ⑤⑥ 才生效。

## ⑤ 阶段5｜写作差异诊断报告（核心环节，不可敷衍）

产出：`05_仿写训练/<周次>/D0n/02_写作差异诊断报告.md`

**先跑机检**：

```bash
$PY $S/style_compare.py --human $W/D0n/_human_corpus.txt \
    --mine <项目>/05_仿写训练/<周次>/D0n/01_AI训练写作初稿.md \
    --out <项目>/05_仿写训练/<周次>/D0n/_style_compare.md
$PY $S/anti_ai_check.py --file <初稿>
```

**再做句级人工诊断**（机检合格 ≠ 无 AI 腔）：

5-0 **【2026-10-01 新增，诊断第一维度】「问题表述强度」专项核验**：
在跑统计之前，先把**「人类如何表述问题」**逐条列出，与初稿对照。四项各自给三列：
`初稿原句 → 真人参考句（附 PMID）→ 差异实质`。

| # | 切面 | 要问的话 | 真人判据（从顶刊池语料实证，勿凭空立） |
|---|---|---|---|
| P1 | **问题命名** | 真人在 Introduction 里**怎么把问题抛出来**？是命名争议，还是铺垫背景？ | 统计顶刊摘要中「待决问题」句（`remains to be determined` / `is unknown` / `whether …`）的每百句值；**与本稿对照** |
| P2 | **断言强度** | 已证机制，真人用什么动词？`may/could` 兜底是不是我一个人的习惯？ | 统计顶刊因果动词（drive/shape/determine/confer/govern）与推测动词（may/might/could）的**比值** |
| P3 | **免责形态** | 结论段有没有**连环免责**（不构成/不等于/宁可不…）？ | 真人用不用？用了几次？**若顶刊 0 次而我有 → 必改** |
| P4 | **保守度差（本日主指标）** | 同一命题，真人句子与本稿的**断言层级差几级**？ | 每句给断言强度 0–3 分（0=纯推测／1=弱化因果／2=直接因果／3=强因果+量化），**算均值与 SD**，与顶刊同题样本对照 |

> 🔴 **元规则（新增，与既有指标体系的关系必须写清）**：
> **指标服务于表述，不反过来约束表述。**
> 若「P4 保守度」显示本稿过保守，而某个机检指标（如 hedge 密度）显示"达标"——
> **以 P4 为准**，把 hedge 降下来。**不得以"机检已达标"为由回退表述强度。**
> 理由：AI 腔的核心不是词频偏差，而是**不敢下判断**。

5-1 **逐条标出 AI 化痕迹**，每条三段式：
- 初稿**原句**（逐字引用，标行号/句序）
- 问题归类（模板堆砌 / 过渡生硬 / 过度绝对 / 空洞套话 / 通篇长难句 / 意义拔高 / 思辨不足 / 中译英直译）
- **真人参考写法**（引句 + PMID，必须来自当日 `语言范式原料.md` 可回溯范围）

5-2 **对比回答**：针对同一个科学内容，真人作者的**处理思路**是什么？句式选择、语气、逻辑上与初稿的区别在哪？

5-3 **总结本次暴露的 3 个最主要短板**，写入 `06_进化复盘/ERROR_DO_NOT_REPEAT.md`（每条须成对：错误句 → 修正句 → 触发条件 → 下周核查）。
