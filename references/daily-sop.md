# 日课 SOP（每日，≥75 篇文献）

> **前置**：周池已建（`01_文献库/<周次>/papers_master.csv`，≥500 篇，IF 分层完整）。
> **固定开场（L4 要求，不可省）**：先读 `03_语言范式库/A~D` 四份累积文件 + `06_进化复盘/ERROR_DO_NOT_REPEAT.md` 中未闭环条目，**口头复述本次专项**，再动手。

## ⓪ 切分当日清单

```bash
PY=<python>
S=<skill>/scripts
W=<项目>/01_文献库/<周次>
$PY $S/daily_pick.py --csv $W/papers_master.csv --week <周次> --day <n> --per-day 74 --out-dir $W/D0n
```

- 自检输出必须满足：`全周并集 = 池总数`、`重复 0 篇`、`当日 ≥74 篇`。
- 若当日不足 74 → 周池不足，先补检索，不得缩量。

## ① 阶段1-1｜文献基础归档

```bash
$PY $S/archive_extract.py --csv $W/D0n/papers.csv --out $W/D0n/归档笔记.md --week <周次> --day <n>
```

每篇必录四栏：**科学问题 / 实验设计类型 / 核心结论 / 局限性**。

**硬约束**：
- 局限栏**只在摘要明确写到 limitation 时填写**；未命中一律写「**摘要未述**」，**不得推断**（摘要未写局限性 ≠ 论文没有局限性）。
- 设计类型基于摘要方法学术语命中，属**下限估计**；未写进摘要的方法不计入，须在统计下方注明。
- 归档是**摘要级**产物。凡进入讨论的细节，须核对是否超出摘要范围。

## ② 阶段1-2｜语言范式深度拆解（本系统核心）

```bash
$PY $S/extract_language.py --csv $W/D0n/papers.csv --out $W/D0n/语言范式原料.md \
    --dump-abstracts $W/D0n/_human_corpus.txt --dump-json $W/D0n/_lang_stats.json
```

原料生成后，**必须人工（模型）完成筛选与归纳**，把结果写入四份累积文件。四类口径见 `language-extraction-protocol.md`：

| 文件 | 内容 | 当日最小增量 |
|---|---|---|
| `A_地道句式清单.md` | 引言/方法/结果/讨论四类地道句式 | ≥3 条新条目（含原文引句 + PMID） |
| `B_逻辑衔接范式.md` | 段落过渡、转折、对比、局限、展望的真人手法 | ≥1 条范式修正或新增 |
| `C_真人写作习惯.md` | 可量化的真人习惯 + 基线值 | 基线表**每周更新**；习惯条目按需新增 |
| `D_AI腔黑名单.md` | 反方向禁忌清单 | 当日新发现的 AI 腔 → 新增条目 |

**要求**：①不提取 = 没读过；②每条必须能回到 `语言范式原料.md` 中的 PMID；③**不重复收录**，发现更优表述用 `[替代 A-xx]` 标记。

## ④ 阶段4｜AI 训练写作初稿（350–500 英文词）

产出：`05_仿写训练/<周次>/D0n/01_AI训练写作初稿.md`

**素材来源**：当日文献的真实科学内容。**禁止脱离原文凭空造科学内容。**

**流程**：
1. 选定题材：优先**当日**有真实公共数据集支撑的方向；记录素材 PMID。
2. 选择段落类型：**Introduction 段** 或 **Discussion 段**（交替练习）。
3. 篇幅：**350–500 词**（硬性；超出或不足必须重写）。
4. 稿首必须带：

```markdown
> ⚠️ 写作训练稿（Training Draft）— 用于写作技法练习，**不得投稿**。
> 素材来源：PMID <...>（<期刊>，IF 区间 <...>）｜未实测数值标 [TO BE MEASURED]
```

5. **允许保留现有 AI 写作习惯**——不刻意伪装完美，保持"可诊断"状态（这是阶段 ⑤ 的输入质量前提）。
6. **不得**为了好看而预先查黑名单改写；黑名单在阶段 ⑤⑥ 才生效。

## ⑤ 阶段5｜写作差异诊断报告（核心环节，不可敷衍）

产出：`05_仿写训练/<周次>/D0n/02_写作差异诊断报告.md`

**先跑机检**：

```bash
$PY $S/style_compare.py --human $W/D0n/_human_corpus.txt \
    --mine <项目>/05_仿写训练/<周次>/D0n/01_AI训练写作初稿.md \
    --out <项目>/05_仿写训练/<周次>/D0n/_style_compare.md
$PY $S/anti_ai_check.py --file <初稿>
```

**再做句级人工诊断**（机检合格 ≠ 无 AI 腔）：

5-1 **逐条标出 AI 化痕迹**，每条三段式：
- 初稿**原句**（逐字引用，标行号/句序）
- 问题归类（模板堆砌 / 过渡生硬 / 过度绝对 / 空洞套话 / 通篇长难句 / 意义拔高 / 思辨不足 / 中译英直译）
- **真人参考写法**（引句 + PMID，必须来自当日 `语言范式原料.md` 可回溯范围）

5-2 **对比回答**：针对同一个科学内容，真人作者的**处理思路**是什么？句式选择、语气、逻辑上与初稿的区别在哪？

5-3 **总结本次暴露的 3 个最主要短板**，写入 `06_进化复盘/ERROR_DO_NOT_REPEAT.md`（每条须成对：错误句 → 修正句 → 触发条件 → 下周核查）。

## ⑥ 阶段6｜两轮强制迭代修改

产出：`03_第1轮修订稿.md`、`04_第2轮最终修订稿.md`。**两轮必须独立，不得合并为一次修改。**

- **第 1 轮（纠错改风格）**：逐条修复诊断报告中列出的全部 AI 腔问题；砍模板套话、调语气、模仿真人审慎叙事。产出后写「本轮主要改动说明」（条目化）。
- **第 2 轮（投稿向精加工）**：在 rev1 基础上优化段落内部逻辑流动、微调学术措辞、**优化长短句搭配**、进一步降低模板感，语言贴近期刊实际投稿文风。
- **全程不变**：全部科学事实（数值、方向、结论）与 rev0 一致。
- rev2 完成后**重跑** `style_compare.py` 与 `anti_ai_check.py`，把 rev0 / rev1 / rev2 三项指标并列写入沉淀文件——**这一步是"进步可量化"的证据**。

---

## ⑦ 阶段7｜当日沉淀

产出：`06_进化复盘/沉淀_<周次>_D0n.md`

必须包含：
1. **本周/当日收获**：值得复用的学术表达要点（条目化）。
2. **避坑清单**：当日踩过的 AI 写作雷区。
3. **3 个主要短板**（来自 ⑤-5-3）。
4. **明日训练改进方向**：下一次同类写作练习重点注意什么。
5. **闭环标记**：错题本中所有条目补「✅ 已进入下次自检清单」。
6. **指标对比表**：rev0 / rev1 / rev2 × { AI 味指数, 连接词密度, hedge/booster, 平均句长, 句长 SD }。
