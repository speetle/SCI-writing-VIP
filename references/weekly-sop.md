## ⑧ 领域前沿研究快报（Word）—— 重要文献的框架级解读

产出：`02_前沿快报/领域前沿研究快报_<周次>_<日期>.docx`

**定位（v2.8 改）**：不是文献计量报告，也不是逐篇摘要汇编，而是**“重要文献用什么方法解决了什么问题、补了什么空白”的解读报告**。文献拆解一律沿用 `framework-dissection-protocol.md` 的三问与 F8/F9，**不得退回摘要复述**。

**篇幅硬约束**：正文 ≤8 页（中文字符 ≤6500，不含附录）；热点 3–5 个；逐篇解读 3–8 篇（每热点 1–2 篇）。**宁可 3 篇读透，不凑 8 篇。**

### 一、选文：什么算“重要文献”（三条全中才入选）

| # | 判据 | 不合格 |
|---|---|---|
| S1 | 直接回答本热点的核心问题 | “也研究了这个方向” |
| S2 | 对该热点核心主张提供了最直接的证据；按主张类型审查 E0–E4、设计与验证，不把 RCT / MR / 单细胞 / 计算筛选简单排成单一等级 | 只有相关性且无验证，或仅用设计名称代替证据审查 |
| S3 | 设计或分析链条对先生方向可迁移 | 结论只在本对象成立且无方法增量 |

排除：综述、社论、评论、纯描述性堆数据、仅生信筛选无验证。**不设凑数篇**；某热点凑不出 1 篇合格文献时，该热点只写空白，不写解读。

### 二、每篇解读卡（七块，缺一不合格）

| 块 | 写什么 | 字数上限 |
|---|---|---|
| ① 采用什么方法 | 设计类型 + 关键手段（一句） | 40 |
| ② 解决了什么问题 | 该文对准的可检验问题（一句，疑问句形态） | 40 |
| ③ 弥补了什么空白 | 缺口类型 G1–G5（见 `section-playbooks.md` §2）+ 补到哪一步（“首次证明”还是“限定条件”） | 60 |
| ④ 方法学体系 | M1–M7 七层，每层一行 ＋ 一行方法-问题映射（见下） | 7 行 + 1 行 |
| ⑤ 证据与结论 | **主张类型｜E级｜关键证据句/数字｜结论原句｜本报告改写｜四把范围锁｜F/I/H**；保留效应量、统计量、n 等承重数字，不得只写结论方向 | 以证据链完整为准 |
| ⑥ 边界 | 只写影响具体结论的具名缺口及其影响（对象 / 对照 / 测量 / 验证 / 随访 / 全文）；不重复 M7，不写通用展望 | 按需 |
| ⑦ 可迁移写法 | 抽象成不带领域词的动作序列 | 50 |

### ④ 的固定七层（M1–M7，完整方法学体系，不得省层）

| 层 | 内容 | 判据 |
|---|---|---|
| M1 研究设计 | 类型 / 对照设置 / 时间方向 / 是否预注册 | 能说出“这是什么设计” |
| M2 对象与样本 | 物种·细胞系·人群 / 纳入排除 / n 的依据 | n 无依据须标“未述依据” |
| M3 数据与测量 | 数据集·平台·测序深度 / 抗体·读数 / 随访长度 | 只写“RNA-seq”不合格 |
| M4 分析或实验链条 | 第 1 步到第 N 步，谁先谁后 | 顺序即论证顺序 |
| M5 验证策略 | 正交方法 / 独立队列 / 回补 / 敏感性分析 | 至少写出一项“排除替代解释” |
| M6 统计与判据 | 检验 / 多重校正 / 效应量 / 阈值 | 不得写“统计学分析”了事 |
| M7 边界与失效条件 | 外推范围 / 已知偏倚 / 方法适用条件 | 写方法本身的失效条件；⑥只写影响具体结论的具名缺口，不重复本层，不写“需进一步研究” |

**方法-问题映射（紧随 M4 之后一行）**：`哪个方法解决因果 / 哪个只解决相关 / 哪个负责外推`，并标 `充分 / 超配 / 欠配`。
**摘要级可得性**：某层摘要未述，写“摘要未述”，**不得推断**；七层缺三层以上，该篇降为“摘要级提及”，不得进解读卡。

### 三、docx 章节骨架（固定五章，不得增章）

1. **数据口径**（≤半页）：时间窗 / 去重后命中 / 入选数 / IF 来源与抓取日 / JIF 与代理双分母 / 阅读深度声明 / 检索式**指向** `search_log.md`（不正文全录）。
2. **热点总览**（1 张表）：方向 / 篇数 / 中位 IF / `>10` 篇数 / **证据已到哪一步 → 可做什么判断 → 还缺什么** / 是否值得切入；不得以篇数代替证据成熟度。
3. **热点逐个解读**（3–5 个）：每热点 = “证据已到哪一步 → 可做什么判断 → 还缺什么” → 1–2 张解读卡 → 空白 2–3 条（每条可直接当选题）。
4. **原创选题灵感 3 条**：主题 + 生信／实验／临床思路（**不预设为生信选题**，先生 2026-10-01 指定）+ 创新点 + 现实研究意义；须可行，不空泛。
5. **冷热提示 + 一句话总结**：哪些方向发文量上涨 / 哪些已内卷；总结落在“高分稿与中低分稿的结构性差别”。

### 四、强制删除（v2.8 起不再输出）

IF 区间分布全表、研究模式构成表、附录剔除统计、方法学趋势宽表、纯生信选题机会独立章、写作观察独立章、逐条文献罗列（改为卡内嵌 PMID）、重复的方法学声明段落、检索式全文附录。
上述内容确需保留的，只允许压成**一句**并入对应章节。

### 五、红线（不得因压缩篇幅而破）

PMID 与 IF 一律保留；不得编造 PMID；官方 JIF 与代理指标严禁混称；摘要级结论不得写成精读发现；单周计数不得表述为趋势；未标来源的百分比不得出现。

生成：`python3 <skill>/scripts/report_md_to_docx.py --md <报告.md> --out <报告.docx>`

**二者不可统一到一个时间窗。**

## ⑧-b 热点速览（精简阅读版，**并行交付**）

产出：`02_前沿快报/<周次>_热点速览.md`

**定位**：⑧ 的**阅读版**，与全量版**并存、不替代**。全量版承担方法学声明与可复现性材料（SOP 强制，且是"未标来源百分比"红线的合规依据）；精简版只承担“给人读”。**由先生 2026-09-24 明确提出的格式偏好，此后每周固定产出。**

**只保留五件事**，删去：检索式原文、剔除统计、研究模式判定规则、附录产出清单、独立的方法学警示章（要点并入对应热点）、独立写作技法章（另存 `03_写作技法库/`）。

1. **一、热点总览表** —— 方向 / 篇数 / 中位 IF / `>5` 占比 / `>10` 篇数 / **生信占比%**（`bins_summary.json` 的 `生信信号占比`，失衡>70% 或 <15% 须在表下注明）/ **证据已到哪一步 → 可做什么判断 → 还缺什么** / 是否值得切入。
   排序按“**可切入价值**”，**不按文献密度**；篇数只描述本周计数，不代替证据成熟度。
2. **二、逐个热点**（每热点三块，缺一不可）：
   - **进展** —— 该方向现在做到哪一步。
   - **重要文献解读卡** —— **沿用 ⑧ 的同一张七块卡**（①采用什么方法 ②解决了什么问题 ③弥补了什么空白 ④方法学体系 ⑤证据与结论 ⑥边界 ⑦可迁移写法），**每热点 1 篇**（选 IF 最高或结构最完整者）。
     - ④ 在精简版允许压成 **4 行**：`M1 设计` / `M2–M3 对象与测量` / `M4–M5 链条与验证` / `M6–M7 统计与边界`；**七层信息不得缺项**，只合并行数。
     - 摘要未述的层写“摘要未述”，**不得推断**。
     - ⚠️ **⑦ 可迁移写法为必填项**——这是精简版区别于全量版的**唯一增量**，也是先生的实际使用目的（学思路）。缺此项则该节不合格。
   - **研究空白** —— 2–3 条，每条须可直接作为选题。
3. **三、高分文章 IF 速查表** —— PMID / 期刊 / IF / 方向 / 一句话发现。
4. **四、一句话总结** —— 通常落在“高分稿与中低分稿的三处结构性差别”。

**硬约束**：

- **标识符一律保留**（PMID、IF），**不得为压缩篇幅而删除**——红线（不编造、可溯源）。
- 思路拆解基于**摘要级**信息时，明确标“摘要未述”，**不得推断**方法学细节；数据订正后转为非 OA 的文献须注明"仅摘要可用"。

- 压缩目标：正文 **≤4 页**，且不超过全量版的 **60%**。
  🔒 **口径＝字节比**（先生 2026-10-05 裁定，`-76` 结清）。行数比**必须同时报出**但仅作参考；两口径分歧时**以字节比为准**。

**操作要点（避免结构割裂）**：全量版把"现象"（第四章）与"缺口"（第八章）分置两处，中隔三章，是冗余感的主要来源。精简版须**按热点聚拢**——同一热点的进展、拆解、空白必须在同一节内连续呈现。此项同时应反馈到全量版的编写顺序。

## ⑧-c 深度拆解（全文级逐图拆解，**按需触发**）

产出：`07_深度拆解/深度拆解_<PMID>_<题材短名>.md`

**定位**：⑧-b 的**下沉模块**。速览的“典型文献思路拆解”是**表格级**（摘要级信息可支撑）；本模块是**全文级**，粒度到每张图的设计参数与论证作用。**由先生 2026-09-25 明确要求**：*"我要的是类似视频中这样比较细致的拆解"*。

**完整规范见 `references/deep-dissection-protocol.md`**，要点：

- 前置须为 **OA 且有 PMCID**；非 OA 只能做摘要级并标 `depth: abstract-only`。
- 五段结构：三十秒版 → 全局骨架表（含“抽掉这一步会怎样”）→ **逐图拆解**（四问：解决什么／怎么做／得到什么／链条位置＋设计讲究）→ 三个关键设计决策 → 可迁移模板 → 弱点清单（**作者自陈 + 本拆解补充，两段不得合并**）。
- 唯一能稳定产出增量价值的环节是**图注与正文交叉核对**（取材部位、补充图实体、细胞类型归属）。
- **每期 ≤2 篇**——单篇成本约等于速览全篇。

**可行率硬约束（W39 实测）**：全池可全文 273/520（52.5%），但 `>10` 区间仅 14/53（**26%**）。**高 IF 文献多数做不了全文级深拆**，选篇与交付说明均须如实交代。
**W41 更新（顶刊池口径）**：顶刊池 `pmcid` 非空 **261/467 = 55.9%** ≥ 20% 阈值 → “逐图深拆”对第二层**成立**；但**候选实测成功率仅 50.0%** → 已加 **②-bis 实测抓取探测**（见下）。

**2026-10-01 起选材改道（先生指定：IF>20 / 近十年 / 三大顶刊为主）**：

- 深拆候选**优先从顶刊 reserve 池取**（`01_文献库/_顶刊池/papers_toppool.csv`，近十年 / IF>20），
  **不再优先从周课主池 `>10` 区间取**——后者 IF>20 只有个位数篇，且可全文率约 27%
  （Nat Med / Cancer Res / JCO / Gut 等顶刊多为订阅制，无 PMCID）。
- **顺序**：① 顶刊池中**有 PMCID 且 ≥2024**（可全文 + 最新）→ ② 顶刊池有 PMCID（可全文，年份不限）→ **②-bis 实测抓取探测**（见下）→ ③ 顶刊池无 PMCID（**只能摘要级深拆，标 `depth: abstract-only`，逐图拆解不施**）→ ④ 才有必要时回落到周课主池。
- 🔒 **②-bis 实测抓取探测（先生 2026-10-05 裁定，`-75` 结清）**：
  **`pmcid` 非空是必要条件、不是充分条件。** 定选前**必须先对候选池逐篇跑一次真实抓取**
  （`scripts/fetch_pmc_fulltext.py --pmcid <PMC…> --dump-md`），**抓到才定选，抓不到即换下一篇**，
  不再按“有 PMCID”直接定选。**候选池规模按目标篇数的 2× 准备。**
  实测依据：W41 候选池 ① 档 73 篇，实测 16 篇仅成功 **8 篇 → 50.0%**。
- **如实交代**：交付说明必须写“本轮 N 篇候选中，有全文 M 篇（M/N = xx%），其余仅摘要级”。
  **不得把摘要级拆解写成全文级**（R4 红线）。

## ⑨-b 顶刊叙事与图表论证链（v2.7 新增，每周随 ⑨ 一并产出）

按 `references/narrative-argument-standard.md` 执行，三件事：

1. **多篇对比扫描（8–15 篇同域）**：建矩阵（问题 / 对象 / 方法 / 结论 / **主张类型与 E级** / 未解决 / 与本文关系）→ 判“已解决透彻 / 仍存空白 / 结论矛盾”。按主张类型选择最直接证据并分层比较，不把 RCT、MR、单细胞、计算筛选简单排入同一等级。矛盾处**必须写出可检验的区分假设**，不得写“存在争议”。
2. **Gap Ledger**：抽本域 2 篇（1 顶刊 + 1 中等）逐行拆“缺口句 → 服务它的设计 → 回答它的图/段 → 讨论回指句”，标出断链类型（有缺口无设计 / 有设计无回答 / 有回答无回收）。
3. **Figure Ledger**：对本周 2 篇深拆对象逐图六问（支撑哪句 / 为何此图型 / 为何在此位置 / 证明什么 / 不能证明什么 / 与前后图关系），并判序列范式（递进链 / 分叉验证 / 正交三角 / 漏斗收敛）。
4. **Claim Ledger**：本周 2 篇深拆对象**每篇 ≥3 条承重结论**，成对登记“证据句/数字 → 结论原句”，并标主张类型、E级、F/I/H、四锁、Q/G/A/F/C 锚点与校准后改写；识别真人样本的过强、过弱和范围越界，不只摘优点。

产出：`04_IMRAD架构库/<周次>_叙事与图表论证.md`，结论回写 §⑩ 框架模板的“图表选择依据”小节。

**判据**：两篇的 Figure Ledger 每图六问**不得有空行**；凡“为何此图型”答成图型名称而非论证理由的，视为未完成。
