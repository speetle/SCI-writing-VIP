# 论文架构拆解与各部分写法协议（并列训练模块）

> 目的：把“读论文”从摘要与句子层面提升到**整篇架构、各部分写法、图表布局、样本 A/B 对照**四个层面。
> 适用：每日读文献、周课 IMRAD、真实稿件结构修改、AI 痕迹诊断。
> 科学内容仍须回到 PubMed 原始文献；本文档定义写法训练，不替代证据核验。

## 一、模块定位与每日操练的关系

本模块与日课 ①–⑦并列，不取代任何阶段。

| 训练层 | 每日操练已有内容 | 本模块新增内容 | 两者如何闭环 |
|---|---|---|---|
| 文献理解 | 归档科学问题、设计、结论、局限 | 拆整篇“为什么这样排、每部分承担什么任务” | ①的四栏提供事实，架构卡解释组织逻辑 |
| 语言学习 | 句式、连接词、真人范式四库 | 按章节比较连接词功能、句长节奏、信息密度 | ②抽句，架构模块标注其在论证链中的位置 |
| 写作训练 | 350–500 词仿写、句级诊断 | 先搭章节骨架，再写段落，再做句级润色 | ④先用架构卡定段落功能，⑤⑥再查 AI 痕迹 |
| 叙事判断 | 三问、Gap Ledger、Figure Ledger | 摘要至结论的跨节回指与图文布局 | C1/C3 提供主线，本模块检查每节是否服务主线 |
| 进化沉淀 | 每日短板、环比指标 | 章节级差异与“人类靠拢”对照账本 | 每日写入章节基线、问题条目、下一轮专项 |

**不可混淆**：架构拆解不是“按顺序复述实验”；每一部分必须回答“本节要让读者完成哪个判断”，并指出它如何承接前节、开启后节。

## 二、整篇文章的总架构

### 2.1 一条主链

`现实问题/领域代价 → 已知进展 → 可检验缺口 → 研究设计 → 证据递进 → 结论边界 → 可迁移贡献`

每篇文章必须填写：

1. **主问题**：一句疑问句。
2. **主缺口**：前人不知道什么，为什么值得解决。
3. **主张**：本文最重要的一句话结论。
4. **证据链**：每个承重结果对应哪种证据、图表和统计。
5. **边界**：本文明确不能推出什么。
6. **贡献**：改变了哪个具体判断，而不是泛泛“提供新见解”。

### 2.2 跨节闭环表

| 节 | 本节必须完成的读者判断 | 输入 | 输出 | 必须回指 |
|---|---|---|---|---|
| Abstract | 是否值得读、主要发现是什么 | 全文 | 压缩后的问题—方法—结果—意义 | 主缺口、主张、关键证据 |
| Introduction | 为什么必须做这项研究 | 领域现状与文献 | 一个可检验缺口与研究目的 | 现实问题、前人结果 |
| Methods | 研究是否可复现、设计能否回答缺口 | Introduction 的 A 句 | 研究对象、测量、分析、验证链 | 缺口与每个研究问题 |
| Results | 证据是否逐层回答问题 | Methods 的设计 | 按论证顺序排列的结果 | 每段回指一个子问题/图 |
| Discussion | 这些结果改变了什么判断 | Results 的证据 | 贡献、比较、机制、边界、下一步 | 主缺口、主张、局限 |
| Conclusion | 读者最终应带走什么 | Discussion 的收束 | 一至三句边界内结论 | 主张与可迁移意义 |
| Figure legend | 不看正文也能读懂图在证明什么 | 图与统计 | 自明的图注 | 图的 claim、样本、统计与边界 |

## 三、逐部分拆解与写法

### 3.1 摘要 Abstract

**架构**：背景收口 → 缺口 → 设计 → 关键结果 → 结论/意义。结果占信息重心，不平均分配字数。

| 拆解项 | 必答问题 | 真人写法 | AI 常见偏差 |
|---|---|---|---|
| 背景 | 不解决会损失什么 | 1句具名对象+后果/负担 | 泛泛“近年来受到关注” |
| 缺口 | 具体不知道什么 | whether/remains unknown，能被本文回答 | “研究较少” |
| 方法 | 用什么设计回答 | 对象、样本、关键手段、验证方式 | 软件清单堆砌 |
| 结果 | 最重要的3个发现 | 方向+效应量+统计量+n | 只写 significantly |
| 结论 | 改变哪个判断 | 一句边界内的知识更新 | valuable insights/foundation |

**写作判据**：抽掉背景与套话后仍应留下“缺口、设计、结果、判断”；结论强度不得超过结果与阅读深度。

### 3.2 引言 Introduction

**四步漏斗**：①大背景收口（1–2句，别扯远）→ ②聚焦前沿（代表性文献及其成果）→ ③找 gap（最重要）→ ④抛出本研究（做了什么、意义是什么）。

**逐段拆法**：每段标记“现状/进展/矛盾/缺口/目的”，并写出转折句为何出现。

**真人写法**：按结论分组文献；先建立一致认识，再指出未解释的差异；每篇引用承担一个动作，不堆作者名。

**AI 偏差**：背景过长、文献逐篇罗列、gap 空泛、用“important/novel”替代问题价值。

### 3.3 方法 Methods

**架构**：研究设计 → 对象与样本 → 数据/材料与测量 → 实验或分析链条 → 验证策略 → 统计判据 → 可复现信息 → 边界。

| 层 | 拆解问题 | 写法判据 |
|---|---|---|
| 设计 | 是观察、干预、队列、RCT、方法学还是资源建库 | 明确时间方向、对照与主要终点 |
| 对象样本 | 谁被研究、n为何合理 | 纳入排除、独立样本、样本量依据 |
| 测量 | 测了什么、如何测 | 平台、试剂、参数、版本、质量控制 |
| 链条 | 哪一步先做、为什么 | 顺序对应论证顺序，避免流水账 |
| 验证 | 如何排除替代解释 | 正交方法、回补、独立队列、敏感性分析 |
| 统计 | 如何判定结果 | 检验、效应量、CI、校正、阈值 |
| 边界 | 设计能推多远 | 明确外推范围与失效条件 |

**方法写法**：通用流程可压缩；决定证据等级的设计必须展开；不要把“做过什么”写成“因此证明什么”。Methods 的句子以可复现为主，少用升华性连接词。

### 3.4 结果 Results

**架构**：研究对象/质量控制 → 主现象 → 关键机制或关联 → 验证/干预 → 外推或边界。实际顺序以论证链为准，不机械按实验时间。

每段固定：**结论主题句 → 关键证据 → 统计与样本 → 边界/阴性结果 → 下一问题过渡**。

**真人写法**：先给结论，再给支撑数字；只写承重数字；阴性结果直写；机制解释留给 Discussion。

**AI 偏差**：每段先写“to investigate”；重复图表所有数字；每段都用“Interestingly/Moreover”；把相关写因果。

### 3.5 讨论 Discussion

**架构**：主要发现 → 与一致文献对照 → 与不一致文献对照及差异变量 → 机制解释 → 理论/现实贡献 → 真局限及其影响 → 可执行展望。

**局限的合格写法**：`局限是什么 → 削弱哪个结论 → 已采取何种缓解 → 读者应如何折扣`。

**真人写法**：不重复 Results 数字；明确哪些是本文直接证明、哪些是合理解释；结论回到 gap；展望写对象、设计和条件。

**AI 偏差**：六段套模板但不回指本文；连续 hedge；“有局限但不影响结论”；展望只有“需要进一步研究”。

### 3.6 结论 Conclusion

**架构**：回答主问题 → 限定证据边界 → 说明可迁移意义/下一步。通常 1段或1–3句，不新增结果、不扩大人群或机制。

| 句 | 功能 | 判据 |
|---|---|---|
| C1 | 直接回答 | 与 Abstract/Discussion 主张同向同强度 |
| C2 | 边界限定 | 指出模型、样本、时间或因果限制 |
| C3 | 意义 | 改变具体判断或提出可执行下一步 |

**AI 偏差**：把摘要重写一遍、连续“may/potentially”、用“opens new avenues”收尾。

### 3.7 Figure 与 Table 的排版布局

#### 图表在整篇中的位置

1. 图序应对应论证递进：现象 → 机制 → 因果/验证 → 外推/边界；若采用其他顺序，必须说明理由。
2. 主图承载改变读者判断的证据；补充图承载质量控制、方法验证和不改变主结论的细节。
3. 同一图内由左至右、由上至下通常遵循“问题拆分 → 证据推进 → 结论收束”；每个 panel 只承担一个可定位动作。
4. 图表首次出现位置应紧跟其要回答的结果段；不要在正文先引用后解释，也不要让图先于问题出现。
5. Table 适合精确比较、样本特征、模型参数和完整统计；Figure 适合趋势、分布、时间过程、空间关系和机制链。

#### 版式拆解字段

| 字段 | 必答内容 |
|---|---|
| Figure claim | 这张图支撑哪一句承重结论 |
| Layout logic | panel 顺序、分组、留白、视觉层级如何引导读者 |
| Encoding | 颜色、形状、线型、误差棒、标注各代表什么 |
| Comparison | 横向比较还是纵向递进，基准组在哪里 |
| Statistics | n、检验、CI、校正、显著性标记是否在图注说明 |
| Text relation | 与前一图、后一图、正文主题句分别是什么关系 |
| Boundary | 图能证明什么，不能证明什么 |

#### 版式规律的训练边界

- 只能基于实际看过的图和图注归纳；未全文/未看图不得断言排版规律。
- 不把“颜色好看、布局整齐”当作科学规律；必须解释布局如何服务比较与论证。
- 每张主图完成 Figure Ledger 六问：支撑哪句、为何此图型、为何在此位置、证明什么、不能证明什么、与前后图关系。

### 3.8 Figure legend

**架构**：结论性标题 → panel 描述 → 对象/处理/读数 → 样本与统计 → 缩写、比例尺和数据来源。

**写法**：标题说明方向或证明任务，不写空泛“Effects of X on Y”；每个 panel 一句；统计、n、误差棒和星号定义齐全；图注脱离正文仍能判断图在证明什么。

## 四、与每日操练逐项对照

### 4.1 必比维度

| 维度 | 样本 A：真人论文 | 样本 B：每日训练稿 | 诊断动作 | 进化指标 |
|---|---|---|---|---|
| 连接词功能 | 转折、因果、限定、递进各自承担逻辑 | 标注每个连接词实际功能 | 逐句标注，不只计总数 | 各类连接词/百句、重复率 |
| 句式长短 | 按章节比较均值、SD、≤15词、≥35词比例 | 同口径计算 | 章内对齐，不能用全文平均掩盖差异 | 均值、SD、短句率、长句率 |
| 信息密度 | 每句是否新增对象、条件、数字、判断 | 删除测试后剩余有效信息 | 统计有效信息句/总句 | 信息密度、空泛句率 |
| 啰嗦与废话 | 真人是否保留承重限定与必要过渡 | 删除形容词、套话、升华句 | 删后≤2句有效信息则整段重写 | 废话句率、删除保留率 |
| 结论强度 | 证据形态对应动词强度 | 对同一命题逐句比对 | 观察性/体外/单模型/因果分层 | 强度差均值、过强/过弱数 |
| 段落架构 | 主题句—证据—边界—过渡 | 训练稿逐段套用后再脱模 | 标每段功能，查缺项 | 功能缺失数、段落可调序率 |
| 图文关系 | 图型、布局、顺序服务 claim | 训练中写 Figure Ledger | 六问逐图核对 | 空 Ledger 数、图文错配数 |
| 术语一致 | 同一变量、方法、终点固定叫法 | 全文建立术语表 | 机检+人工裁决 | 变体数、高危替换数 |

### 4.2 连接词对照口径

先按功能分类，再比较频率：

- 因果：therefore, thus, thereby, because
- 转折/对照：however, whereas, in contrast, although
- 递进：furthermore, additionally, moreover
- 限定：within, among, under, particularly, to the extent that
- 时间/顺序：first, subsequently, thereafter, finally

**判定原则**：真人不是连接词越多越好，而是连接词出现时确实改变读者的推理方向。连续使用 moreover/in addition、段首模板化连接词、用 however 代替真正矛盾，均计为 AI 倾向。

### 4.3 结论强度对照

| 证据 | 可用强度 | 禁止 |
|---|---|---|
| 观察性关联 | associated with / co-varied with | caused / drives |
| 体外单一模型 | in this model, reduced | 无限定普适结论 |
| 单一动物模型 | in this model / supports | in humans |
| 敲低与回补 | required for / sustains | sufficient for（未做过表达） |
| 多模型正交验证 | supports / confirms | 超出验证范围的普适化 |

**两种偏差都要纠正**：过强是科学越界，过弱是 AI 式免责。以证据决定强度，不以“听起来安全”决定。

## 五、AI 写作与真人写作的归纳

| 方面 | AI 典型特点 | 真人论文特点 | 靠拢动作 |
|---|---|---|---|
| 架构 | 各段都像完整小作文，跨节回指弱 | 每节只完成一个判断，整篇共享主缺口 | 先写 G/A/F/C 四句，再写段落 |
| 行文 | 连接词密集且功能重复 | 连接词少而精确 | 按功能分类后删重复连接词 |
| 句长 | 章内节奏趋同，长句堆叠或机械短句 | 论证章较长，事实章较短，长短有功能 | 用章节基线对齐，不追求全文平均 |
| 信息 | 形容词、意义句、套话占比高 | 每句带对象、条件、数字或判断 | 删除测试；剩≤2句则按结果+依据+判断重写 |
| 叙事 | 先做什么再做什么，缺口与结果脱节 | 结果按回答问题的顺序排列 | 每段填写“回答哪个子问题” |
| 结论 | 要么过度保守，要么无依据拔高 | 强度与证据、边界一致 | 做 H3 双向校准 |
| 图表 | 图表像结果仓库，布局不服务论点 | 每张图有唯一承重 claim | Figure Ledger 六问 |
| 讨论 | 套“意义—局限—展望”模板 | 比较差异、解释边界、回收缺口 | 先写回指句，再写贡献与局限 |
| 术语 | 为避免重复主动同义替换 | 变量和方法名称稳定 | 术语表 + 机检 + 人工裁决 |

## 六、每日可直接执行的新增步骤（与日课并列）

### A. 架构卡（每日全部文献）

每篇补填：主问题、主缺口、各节功能、F8 叙事排法、F9 闭环、图表承重关系、结论边界、depth。

### B. 选 3 篇做“各部分写法卡”

每篇至少标摘要、引言、方法、结果、讨论、结论、图注；全文可得时增加图表布局字段。摘要级不得评价全文方法或图表布局，写“摘要未述”。

### C. 样本 A/B 对照

每日仿写稿至少抽 1 个段落，按 4.1 的八个维度逐项对照；输出“真人句/训练句/差异/下一步动作”。

### D. 当日沉淀

新增：章节级指标、3 个 AI 废话实例、1 个结论强度校准实例、1 个图文布局观察、次日专项。

### E. 周度汇总

每周更新：章节句长基线、连接词功能分布、废话句率、强度差、图文错配数；只把连续 ≥4 周同向变化称为趋势。

## 七、完成判据

- 每篇有整篇架构卡，不是实验流水账。
- 每日 3 篇有七部分写法卡；可得全文者完成图表布局拆解。
- 样本 A/B 已按连接词、句长、信息密度、废话、结论强度、图文关系逐项对照。
- 章内指标已记录，不能只报全文平均。
- 至少 3 个 AI 废话实例完成“原句→删除测试→真人式改写”。
- 至少 1 个结论完成强度校准，并注明证据依据。
- 至少 1 张图完成布局与 Figure Ledger 六问。
- 新条目含原文引句与 PMID；摘要级结论未越界。
