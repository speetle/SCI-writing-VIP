# EVOLUTION_LEDGER — 写作能力进化账本（L2 记忆）

> 用途：让「每周进步」有数字可依。
> 计分：10 维度，每维 1–5 分，总分 50。
> 有效进步判据：总分环比 ≥ +3，或任一曾失分维度 ≥ +1。连续两周无提升 → 触发 S6 调整。

## 评分维度速查

| 代号 | 维度 | 5 分标准 |
|---|---|---|
| D1 | 研究空白陈述 | 一句话点明「已知边界 + 未知缺口 + 为何重要」 |
| D2 | 论证链条 | claim 紧跟 evidence，无跳步 |
| D3 | 结果叙事 | 数据按逻辑推进而非按实验顺序罗列 |
| D4 | 句式多样性 | 长句/短句/名词化交替 |
| D5 | 动词精确性 | demonstrate/attenuate/abrogate 各就其位 |
| D6 | 段落主题句 | 首句即结论 |
| D7 | 过渡与衔接 | 逻辑承接而非连接词堆叠 |
| D8 | 局限与展望 | 具体、诚实、可执行 |
| D9 | 术语与惯例 | 一致且合领域约定 |
| D10 | AI 味指数 | 5 = 读不出机器痕迹（反向计分） |
