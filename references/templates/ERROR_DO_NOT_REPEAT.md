# ERROR_DO_NOT_REPEAT — 错题本（L3 记忆）

> 用途：把已犯的写作错误变成**可执行的核查项**，防止重复。
> 铁律：每条必须成对给出「错误句 → 修正句」；无对照的条目一律作废。
> 闭环：每周 S6 结束时，未标 ✅ 的条目必须补「已进入下周清单」标记，否则本轮视为未闭环。

**当前状态**：初始化于 2026-09-21，尚无条目。

## 条目格式（强制）

```markdown

- **为何错**：
- **修正句**：*"..."*
- **触发条件**：什么情况下最容易犯（用于自检时定位）
- **类别**：AI味 / 逻辑 / 语法 / 术语 / 数据表述 / 结构
- **下周核查**：☐ 待进入 / ✅ 已进入 W__ 自检清单
```
