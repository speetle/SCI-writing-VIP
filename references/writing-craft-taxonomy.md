# 技法分类体系与抽取话术（Craft Taxonomy）

## 一、四大类

### A. 结构范式（Structure）
论文骨架层面的可复用模式。

| 子类 | 抽取什么 | 例 |
|---|---|---|
| A1 摘要骨架 | 背景句→缺口句→方法句→结果句→意义句的**字数配比与句序** | 高 IF 论文常把缺口句压到 1 句、结果句给 3 个具体数字 |
| A2 Introduction 漏斗 | 领域→子领域→已知→缺口→本研究的分层数 | 4 段式 vs 3 段式 |
| A3 缺口句位置 | 缺口出现在 Intro 第几段、以什么句式收口 | 末段最后一句，用 whether/remains 结构 |
| A4 Results 叙事序 | 按实验顺序 vs 按逻辑推进 | 高分论文多为「表型→机制→临床价值」 |
| A5 Discussion 镜像 | 与 Results 的一一对应方式 | 每段首句回指一个具体发现 |
| A6 Limitation 段 | 数量、具体度、与展望的绑定 | 3 条具体局限 + 2 条可执行下一步 |

### B. 语言与句式（Language）
句子层面的表达技艺。

| 子类 | 抽取什么 | 例 |
|---|---|---|
| B1 主题句 | 段首句如何直接给结论 | `X suppressed Y in a dose-dependent manner.` |
| B2 动词强度 | demonstrate/attenuate/abrogate/associate 的选用梯度 | 「相关性」绝不用 demonstrate |
| B3 名词化 | 用名词短语替代从句以压缩信息 | `the failure of Z to respond` |
| B4 限定语 | may/likely/consistent with 的分布 | 结论句几乎必带限定 |
| B5 对比结构 | Although/Whereas/In contrast 的用法 | 用于制造张力而非堆砌 |
| B6 数值嵌入 | 数字放在句子的哪一位 | 高分论文把关键数字放句末 |
| B7 过渡 | 靠逻辑承接（This increase translated into...）而非 moreover | 见 anti-ai-checklist 第 3 条 |

### C. 论证与证据（Argument）
逻辑层面的技艺。

| 子类 | 抽取什么 |
|---|---|
| C1 claim-evidence 距离 | 论断与证据间隔几个句子（越小越强） |
| C2 证据台阶 | 从相关→预测→机制→干预的递进设计 |
| C3 反证处理 | 如何处理与假设不符的结果 |
| C4 边界声明 | 如何界定适用人群/条件 |
| C5 因果措辞 | 观察性研究如何避免因果动词 |

### D. 图表与数据呈现（Figure）
| 子类 | 抽取什么 |
|---|---|
| D1 图表自明性 | 标题是否独立可读 |
| D2 主图序列 | 每张主图承担一个论证任务 |
| D3 补充材料分工 | 什么进主图、什么进补充 |
| D4 生信专有 | 森林图/热图/KM 曲线/ROC 的呈现惯例与图注写法 |

## 二、抽取话术（提问模板）

对每篇 L2 文献依次问：

1. 摘要的**缺口句**是哪一句？请抄原文。它在全文 Intro 的哪个位置？
2. 哪个**动词**是全文的关键动词？换成弱动词会损失什么？
3. Results 的第 1 段做了什么？它承担了什么论证任务？
4. 哪一句话让你觉得「这个结论站得住」？它凭什么站得住？
5. Discussion 的 limitation 有几条？其中哪条是**真局限**（会削弱结论）而非客套？
6. 这篇论文如果让我写，我最可能写成什么样（差版本）？差在哪？

第 6 问是**迁移训练的核心**——它直接产出 S4 的改进点。

## 三、条目格式（强制）

```markdown
### [CRAFT-<周次>-<序号>] <一句话命名>
- **类别**：A2 / B2 / C1 / D4（四选一）
- **原句**：>*"..."* — PMID: xxxxxxxx
- **机制**：为什么这样写更有效（1–2 句，须可验证，不写「更专业」这类空话）
- **迁移模板**：可直接套用的句型骨架
- **适用**：出现位置（Abstract / Intro 末段 / Results 首段 …）
- **反面**：✗ <低质量对照写法>
- **使用记录**：W39 未使用 / W40 已用于训练稿 §3.2
```

## 四、质量门槛

一条技法只有同时满足下列条件才算有效：

- [ ] 有**原文引句**（不是转述）
- [ ] 有 **PMID**
- [ ] 「机制」部分**可被证伪**（能说出「若改成 X，则读者会误解为 Y」）
- [ ] 有**反面写法**对照
- [ ] 「迁移模板」是**骨架**而非某个具体领域的整句

不满足任一条 → 退回重写，不得入库。
